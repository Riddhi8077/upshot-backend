# Upshot Backend

Backend service for the UpshotX platform built using Node.js and Express.  
This project handles API logic, environment configuration, and server setup for production deployment.

---

## Features
- Express-based backend server
- Environment variable configuration
- Razorpay payment integration
- Production-ready deployment setup (Railway)
- Modular and clean server architecture

---

## Tech Stack
- Node.js
- Express.js
- JavaScript (ESM)
- MongoDB
- Razorpay
- Railway
